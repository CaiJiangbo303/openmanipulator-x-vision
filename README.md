# OpenMANIPULATOR-X Vision

This project is for vision-based grasping of the OpenMANIPULATOR-X robotic arm.

- The manipulator has 4 joints plus a gripper.
- Future goals include RGB-D perception, multi-object recognition, object tracking, dynamic object grasping, and 4DOF grasp feasibility assessment.
- The current stage focuses only on building an independent vision engineering framework.
- This repository does not modify the original manipulator-x project.
